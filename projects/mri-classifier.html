MRI Tumor Classifier

A classification and explainability prototype for brain MRI images, built by Teal Stack Studios.

Role
AI & ML engineer · Sole developer
Methods
CNNs · VGG16 · Grad-CAM
Category
AI and deep learning

Make a prediction easier to inspect

MRI classifiers can return a label without making their behavior easy to inspect. This project explores brain tumor classification with multiple CNN approaches and pairs the prediction with a visual explanation inside a straightforward GUI.

Compare models and visualize focus

CNN-based models, including a pre-trained VGG16, were developed and compared. The selected inference flow connects to a GUI that accepts an MRI image and presents a predicted class.

Grad-CAM generates a heatmap overlay to help visualize image regions that influenced the model’s prediction.

A prototype for exploration

The prototype accepts an MRI image, returns a predicted tumor class and displays a Grad-CAM heatmap alongside the scan. The heatmap provides model-focused localization for exploration; it is not pixel-accurate segmentation or a clinical diagnosis.
